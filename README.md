# Bizupon-mangolia

A simple car booking and management website built with HTML, CSS, and JavaScript.

## Project Overview

This repository contains a static website for Bizupon Mangolia, including user-facing pages, admin pages, and support for vehicle tracking and booking.

## Included Files

- `index.html` — Main landing page
- `login.html` — User login page
- `register.html` — Registration page
- `user-login.html` — Alternate user login page
- `tracker.html` — Vehicle tracking page
- `vehicle.html` — Vehicle listing page
- `components.html` — Shared UI components and additional pages
- `calculator.html` — Cost calculator page
- `admin/` — Admin panel pages and forms
- `css/` — Stylesheets
- `javascript/` — Front-end scripts
- `images/` — Site images and assets

## How to Use

1. Clone the repository:
   ```bash
git clone https://github.com/devshwta/Bizupon-mangolia.git
   ```
2. Open the project folder in your code editor.
3. Open any `.html` file in a browser to view the site.

## Development Notes

- No build tools are required. The project runs as a static website.
- If you want to make changes, edit the HTML, CSS, or JavaScript files directly.
- The `.vscode/` folder is ignored from version control to keep local editor settings private.
